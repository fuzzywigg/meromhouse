# Performance pass — 2026-10-07

Lighthouse performance audits against local Cloudflare Pages (`wrangler pages dev`, `http://127.0.0.1:8788/`). Tooling: `lighthouse@12.8.2`, headless Chrome.

No copy/text content was changed (including grant, nonprofit, or Sullivan County wording — none present).

## Before

| Form factor | Performance | FCP | LCP | TBT | CLS | Speed Index | TTI |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Mobile | **100** | 0.7 s | 0.8 s | 90 ms | 0.036 | 0.7 s | 0.9 s |
| Desktop | **100** | 0.2 s | 0.3 s | 0 ms | 0.002 | 0.2 s | 0.3 s |

Baseline notes:

- HTML document ~18.7 KiB; page transfer ~7 KiB including API calls.
- No content `<img>` in the document; `og-image.jpg` was **974,483 bytes** (2848×1504) and only referenced from Open Graph / Twitter meta tags.
- CSS and JS were fully inline; font stack was system UI (no webfont preload).
- Raw reports: `/opt/cursor/artifacts/lighthouse-before/{mobile,desktop}.report.{json,html}`

## Changes

1. **Images**
   - Re-encoded `og-image.jpg` to 1200×630 (**106,494 bytes**, ~89% smaller).
   - Added next-gen siblings: `og-image.webp` (~90 KiB), `og-image.avif` (~54 KiB). Meta tags keep `.jpg` for crawler compatibility.
   - Added below-fold footer `<picture>` with AVIF → WebP → JPEG fallbacks (`og-image-600.*` at 320×168), `width`/`height`, `loading="lazy"`, `decoding="async"`, `fetchpriority="low"`.
   - `main` uses `min-height: calc(100vh - 12rem)` so the lazy preview stays below the first viewport (avoids becoming LCP).
2. **Render-blocking JS**
   - Moved dashboard logic to `/assets/dashboard.js` loaded with `defer` from `<head>` (parser-blocking inline script removed).
3. **CSS**
   - Kept critical CSS inline (avoids an extra render-blocking stylesheet request on this small page).
   - Reserved `min-height` on `.card-value` to reduce CLS when live stats populate.
4. **Fonts**
   - Self-hosted Source Sans 3 Latin (400/600/700) under `/fonts/` (SIL OFL).
   - Preloaded the critical 400 weight WOFF2; `font-display: optional` on all faces.
5. **Caching**
   - Longer `Cache-Control` for `/fonts/*`, OG image variants, and `/assets/*` in `_headers`.

After notes:

- Performance score held at **100** on mobile and desktop.
- Mobile **TBT** improved (90 ms → 10 ms); mobile **CLS** improved (0.036 → 0.001).
- Absolute LCP rose slightly with self-hosted fonts + deferred script discovery; scores remain maxed.
- Social/OG payload: `og-image.jpg` **974,483 → 106,494 bytes**.
