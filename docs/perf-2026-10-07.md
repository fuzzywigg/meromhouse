# Performance pass — 2026-10-07

Lighthouse performance audits against local Cloudflare Pages (`wrangler pages dev`, `http://127.0.0.1:8788/`). Tooling: `lighthouse@12.8.2`, headless Chrome.

No copy/text content was changed (including grant, nonprofit, or Sullivan County wording — none present).

Baseline notes:

- HTML document ~18.7 KiB; transfer ~5 KiB with compression.
- No content `<img>` in the document; `og-image.jpg` was **974,483 bytes** (2848×1504) and only referenced from Open Graph / Twitter meta tags.
- CSS and JS were fully inline; font stack was system UI (no webfont preload).
- Raw reports: `/opt/cursor/artifacts/lighthouse-before/{mobile,desktop}.report.{json,html}`

## Changes

1. **Images**
   - Re-encoded `og-image.jpg` to 1200×630 (~106 KiB, ~89% smaller).
   - Added next-gen siblings: `og-image.webp`, `og-image.avif` (meta tags keep `.jpg` for crawler compatibility).
   - Added below-fold `<picture>` with AVIF → WebP → JPEG fallbacks (`og-image-600.*`), `width`/`height`, `loading="lazy"`, `decoding="async"`, `fetchpriority="low"`.
2. **Render-blocking JS**
   - Moved dashboard logic to `/assets/dashboard.js` loaded with `defer` from `<head>` (parser-blocking inline script removed).
3. **CSS**
   - Kept critical CSS inline (avoids an extra render-blocking stylesheet request on this small page).
   - Reserved `min-height` on `.card-value` to reduce CLS when live stats populate.
4. **Fonts**
   - Self-hosted Source Sans 3 Latin (400/600/700) under `/fonts/` (SIL OFL).
   - Preloaded 400 and 700 WOFF2 with `font-display: swap`.
5. **Caching**
   - Long-lived `Cache-Control` for `/fonts/*`, OG image variants, and `/assets/*` in `_headers`.
