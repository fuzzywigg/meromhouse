## Prioritized fix list

Ordered by user impact / standards severity. Each item notes open draft PRs that **likely already address** it (do not merge from this audit PR).

### P0 — Accessibility (blocking for 100 a11y)

1. **Distinguish the inline `hub` link without relying on color alone**  
   - **Where:** Uptime card row `link · hub` in `index.html`.  
   - **Fix:** underline (or other non-color cue) and/or raise link-vs-surrounding contrast ≥ 3:1; keep existing `:focus-visible` ring.  
   - **Evidence:** LH `link-in-text-block` (mobile + desktop); axe `link-in-text-block` (serious).  
   - **Open PRs:** **#25** does not change this link styling — **still open after #25**. **#27** / **#29** only assert; they do not fix.

### P1 — Landmark / keyboard structure

2. **Put `#refresh-bar` inside a landmark (or give it a role)**  
   - **Where:** `#refresh-bar` before `<main>`.  
   - **Fix:** move into `<header>`, wrap in `<aside>`/`role="status"`, or fold into `<main>` after skip target.  
   - **Evidence:** axe `region` (moderate).  
   - **Open PRs:** **#25** adds skip link + `main id="main"` + labelled `<section>` cards but **leaves `#refresh-bar` as a bare div** — region issue likely **persists** until a small follow-up. **#27** covers landmark smoke for header/main/footer, not necessarily this bar.

3. **Ship skip link + labelled card sections**  
   - **Where:** top of document + each dashboard card.  
   - **Evidence:** qualitative gap (axe did not fail missing skip link; cards as divs inside `<main>` are OK for `region` once content is in `<main>`).  
   - **Open PRs:** **#25** (implementation); **#27** (Playwright coverage).

### P2 — Runtime honesty / resilience (not LH fails)

4. **Harden `/api/health` + `/api/github-stats` edge cases** (timeouts, partial upstream, `Cache-Control: no-store` on bad/partial, degraded KV).  
   - **Open PRs:** **#26**.

5. **Cache honesty: reject age-stale KV; abort in-flight polls on hide / overlap** so UI does not flash stale or “unavailable” spuriously.  
   - **Open PRs:** **#28** (complements #26).

6. **Document that `/api/health` polling pauses when the tab is hidden** (matches client).  
   - **Open PRs:** **#24** (docs + test); **#25** folds this into a broader a11y/docs change.

### P3 — Regression safety

7. **Playwright smokes for refresh bar, health row, and baseline a11y** (`lang`, landmarks, `aria-live`, decorative dots, focus ring, `noopener`).  
   - **Open PRs:** **#27**.

8. **`prefers-reduced-motion` + noscript note smokes**  
   - **Open PRs:** **#29** (stacks on #27).

### P4 — Performance insight (optional)

9. **`network-dependency-tree-insight`**  
   - Local post-load fetches of `/api/github-stats` and `/api/health` create a short critical chain. Performance category is already **100**; defer unless production LCP/TBT regress. Deferring stats fetch until after paint, or marking requests lower priority, would quiet the insight.  
   - **Open PRs:** none of #24–#29 target this.
