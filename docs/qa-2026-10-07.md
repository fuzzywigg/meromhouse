## Defects found and fixed

Technical markup / a11y only; visible wording unchanged aside from HTML entity encoding.

1. **Invalid void-element syntax** — `<meta … />` and `<link … />` used XML self-closing form. Fixed to omitted end tags per HTML5 / `void-style`.
2. **Unescaped `&` in markup** — card header `Writing & Content` failed `no-raw-characters`. Encoded as `Writing &amp; Content` (renders the same).
3. **Decorative status dot** — `#gh-dot` lacked `aria-hidden="true"` while `#site-dot` already had it. Added for consistency with assistive tech.

### Not found

- No broken internal asset paths (`/public/favicon.*`, `/site.webmanifest`, `/og-image.jpg`, sitemap loc).
- No in-page `#` hash links (and no dangling anchors).
- No `<img>` elements, so no missing `alt` text on images.
